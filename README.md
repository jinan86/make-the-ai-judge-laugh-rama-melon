## The entry

> The meeting room is booked solid until Thursday, mostly by people hiding from meetings in other rooms.

One line, 102 characters. The program writes it deterministically to `/output/entry.txt`.

## Why this angle

After reading the 440 submissions already in the competition, the saturated angles were avoided: the printer that reads/jams urgent documents, "per my last email", reply-all loops, meetings that should have been emails, endless standups, the office plant outliving managers, HR calling the company a family, Slack statuses, and trust falls. This joke uses a fresh, true office observation instead — meeting rooms booked solid by people hiding from other meetings — with the twist landing on the last words.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

Requires Python 3. No dependencies, no network, no secrets.
